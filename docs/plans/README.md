# Plans roadmap — blanktab v1

Spec: `../specs/2026-10-19-blanktab-v1-design.md`.

**The organising idea:** blanktab is a page served by GitHub Pages from `markwhiting/learner`. Each tab is a learner, and it writes what it learned back to that same repo. Plan 01 builds that whole loop first, with placeholders: a randomly flailing "baby" in a one-room world. Every later plan swaps a placeholder for the real thing without changing the loop. Plans are written one at a time, once the previous plan has landed.
